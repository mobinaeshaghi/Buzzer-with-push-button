# Buzzer-with-push-button
گزارش کار ازمایش  buzzer with push button

نام و نام خانوادگی:مبینا اسحاقی

استاد:اقای دکتر عباسی

عنوان آزمایش: استفاده از push button برای فعال‌سازی buzzer 

هدف آزمایش: 

هدف از این آزمایش یادگیری نحوه استفاده از push button برای روشن و خاموش کردن buzzer است.

وسایل مورد نیاز:

برد آردوینو (Arduino Uno) 💻

buzzer 🔊

push button 🕹️

سیم‌ها 🔌

لپ‌تاپ یا کامپیوتر برای برنامه‌نویسی آردوینو 💻

نرم‌افزار آردوینو IDE 🖥️


شرح آزمایش:

1. اتصال قطعات:

   
پایه یکی از طرف‌های push button به پایه دیجیتال آردوینو (مثلاً 7) وصل می‌شود. 🕹️

طرف دیگر push button به پایه GND آردوینو وصل می‌شود.

پایه مثبت buzzer به پایه دیجیتال آردوینو (مثلاً 8) وصل می‌شود. 🔊

پایه منفی buzzer به پایه GND آردوینو وصل می‌شود. 🔴


2. عملکرد:


وقتی که push button فشرده می‌شود، مدار بسته شده و buzzer روشن می‌شود.

وقتی که push button رها می‌شود، مدار باز شده و buzzer خاموش می‌شود.


نتیجه‌گیری: این آزمایش به شما کمک می‌کند تا با نحوه استفاده از push button برای فعال‌سازی buzzer آشنا شوید. این مدار در بسیاری از پروژه‌ها مانند سیستم‌های هشدار و یا دکمه‌های ساده کاربرد دارد.
